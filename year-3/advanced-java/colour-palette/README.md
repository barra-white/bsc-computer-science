# Colour Palette

CA Assignment 3 — Advanced Java (CS3318), Year 3, BSc Computer Science.

A colour palette management system built with Maven. `Colour` models an RGB colour with range validation; `ColourTable` is a fixed-capacity palette (size must be a power of 2, max 1024) supporting add, contains and lookup by index. Includes JUnit 5 tests.

## Usage

```bash
mvn test
```
