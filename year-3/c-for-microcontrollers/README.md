# C for Microcontrollers

C for Microcontrollers (CS3514), Year 3, BSc Computer Science — Arduino sketches (C/C++).

| # | File | Description |
|---|------|-------------|
| 1 | `reaction_game.ino` | Two-player reaction game — players race to press their button after the buzzer, using pin-change interrupts; best of 3 rounds with LED indicators and serial results |
| 2 | `consecutive_pin_detector.ino` | Lights a red LED when any two consecutive PORTD pins are HIGH, green when two consecutive are LOW |
| 3 | `buzzer_piano.ino` | Plays notes (C4–C5) on a buzzer — either a tune from a serial string, or live keyboard-style play |

Each sketch is self-contained; open in the Arduino IDE and flash to the target board.
