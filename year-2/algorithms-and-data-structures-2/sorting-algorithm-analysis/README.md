# Sorting Algorithm Analysis

CA Assignment 1 — Algorithms & Data Structures 2 (CS2516), Year 2, BSc Computer Science.

Implements and benchmarks Insertion Sort, Merge Sort, Heap Sort and Quick Sort on randomly shuffled and nearly-sorted lists of varying sizes and duplicate counts.

## Files

| File | Description |
|------|-------------|
| `sorting_algorithms.py` | Sorting algorithm implementations |
| `evaluation.py` | Test harness: list generation, timing, evaluation functions (Parts 1-6) |
| `main.py` | Driver script — set parameters, uncomment the desired evaluation runs |

## Usage

```bash
python3 main.py
```
