# Computer Architecture

Computer Architecture (CS2507), Year 2, BSc Computer Science — MIPS assembly labs (MARS simulator).

## Labs

| Folder | File | Description |
|--------|------|-------------|
| `lab-01` | `int_to_binary.asm` | Read a 2-digit integer, print its binary representation bit-by-bit |
| `lab-02` | `ieee754_float.asm` | Parse a real number, print its IEEE-754 sign, exponent and fraction bits |
| `lab-03` | `seven_segment_keypad.asm` | Hex keypad input to a 7-segment display, looping until 'F' is pressed |
| `lab-04` | `exceptions_interrupts.asm` | MIPS exception and interrupt handling via the kernel segment |
| `lab-05` | `matrix_vector_multiplication.asm` | Multiply vector A by matrix B, store into vector C (cache-focused) |
