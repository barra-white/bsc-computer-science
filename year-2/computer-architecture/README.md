# Computer Architecture

Computer Architecture (CS2507), Year 2, BSc Computer Science — MIPS assembly labs (MARS simulator), in lab order.

| # | File | Description |
|---|------|-------------|
| 1 | `int_to_binary.asm` | Read a 2-digit integer, print its binary representation bit-by-bit |
| 2 | `ieee754_float.asm` | Parse a real number, print its IEEE-754 sign, exponent and fraction bits |
| 3 | `seven_segment_keypad.asm` | Hex keypad input to a 7-segment display, looping until 'F' is pressed |
| 4 | `exceptions_interrupts.asm` | MIPS exception and interrupt handling via the kernel segment |
| 5 | `matrix_vector_multiplication.asm` | Multiply vector A by matrix B, store into vector C (cache-focused) |
