# Space Invaders

CA Assignment 2 — Intermediate Programming (CS2513), Year 2, BSc Computer Science.

A Space Invaders clone built with Pygame. Move the paddle with the arrow keys and press space to fire; enemies sweep across and descend, and the round resets faster once all are destroyed.

## Setup

```bash
pip install -r requirements.txt
```

## Usage

```bash
python3 main.py
```

Requires the `images/` folder (`background.jpg`, `invaderGIF.gif`) alongside `main.py`.
