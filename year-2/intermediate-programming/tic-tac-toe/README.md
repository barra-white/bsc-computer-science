# Tic-Tac-Toe

CA Assignment 1 — Intermediate Programming (CS2513), Year 2, BSc Computer Science.

Two-player command-line tic-tac-toe. Players alternate placing X / O on a 0-8 grid; a win increments that player's score, and a drawn board is settled by a rock-paper-scissors tiebreak.

## Usage

```bash
python3 tic_tac_toe.py
```
